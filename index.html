Contexto y Planteamiento del Problema

El Problema: Los estudiantes sufren problemas de retención de memoria y pérdida de información porque durante las clases deben prestar atención y tomar apuntes "a la ligera" simultáneamente, lo que genera notas incompletas y difíciles de entender después.

La Solución (MemoClass AI): Esta aplicación utiliza Inteligencia Artificial para transformar esos apuntes rápidos y desordenados de cada clase en un plan de estudio estructurado que indica exactamente:

  • Qué se aprendió: Resumen claro que reconstruye la clase.
  • Conceptos clave a tener en cuenta: Glosario estructurado.
  • Qué estudiar y reforzar: Vacíos detectados y checklist interactivo.
  • Tarjetas de Memoria (Flashcards): 3 tarjetas interactivas 3D.
Motor de Inteligencia Artificial

Configuración de Google Gemini API

MemoClass AI se conecta mediante fetch al modelo Google Gemini (gemini-2.5-flash). Si no ingresas una API Key o estás sin internet, funciona automáticamente con el Modo Simulación Inteligente Local.

Estado actual: Modo Simulación Inteligente Local Activo (100% funcional sin llave externa).
Aplicación Instalable PWA

Instalar MemoClass AI en tu celular

MemoClass AI se puede instalar en tu teléfono Android (como Moto G) o en tu computador para abrirse como una aplicación nativa:

  1. En Chrome para Android, toca el menú de tres puntos (⋮) arriba a la derecha.
  2. Elige "Instalar aplicación" o "Agregar a la pantalla principal".
